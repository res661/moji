# Moji — прототип Telegram Mini App

Кликабельный мобильный прототип [@moji_app](https://t.me/moji_app). Чистая геймификация, без крипты.
Работает в браузере и как Telegram Mini App.

Сейчас в демо один моджи — **Дракоша**. Арта персонажа в сборке нет: на всех экранах стоит
аккуратный слот «твой моджи». Как только появится оригинальный PNG, его достаточно положить в
`assets/mascots/dino/` (или нарезать через `tools/cut_sheet.py`) — слот заменится сам.

Интерфейс: нейтральный iOS / Telegram (светло-серые поверхности, чёрный текст, системный синий).

## Как открыть

```bash
python3 -m http.server 8765 --directory . --bind 0.0.0.0
```

Сохранение: `localStorage` (`moji-save-v2`). Сброс — на экране «Серия».

## Подложить арт

```bash
python3 tools/cut_sheet.py /path/to/original.png --rows 2 --cols 4
```

Без подписей на шите добавь `--label-frac 0`. Путь: `assets/mascots/dino/<state>.png`.

## Что настоящее, что заглушка

| Есть | Заглушка |
|---|---|
| Весь поток, сохранение, анимации, слоты арта | Бэкенда нет |
| Telegram WebApp SDK, хаптики, theme params | Stars — честный демо-модал, оплаты нет |
| Скачивание карточки (html2canvas) | Арта персонажа нет, пока не придёт оригинальный шит |
